# Auto-Research and Broader Agentic Systems

Auto-research systems connect multiple scientific stages: idea generation, literature review, experimental design, coding, execution, result analysis, writing, and review. This guide also tracks broader agent repositories that are not strictly scientific-agent papers but strongly influence autonomous research workflows.

## System Families

| Family | What it contributes | Repositories to watch |
| --- | --- | --- |
| Automated research loops | End-to-end idea, experiment, writing, and review workflows. | SakanaAI/AI-Scientist, SakanaAI/AI-Scientist-v2, AgentLaboratory, CycleResearcher, Agon. |
| Research ideation systems | Hypothesis generation, novelty checking, and research planning. | AI-Researcher, SciMON, CoI-Agent, Deep Ideation. |
| Coding agents | Repository editing, debugging, testing, and benchmark-driven repair. | OpenHands, SWE-agent, MetaGPT, smolagents. |
| Browser and tool agents | Web interaction, data collection, and external service control. | browser-use, AutoGPT, LangGraph-based browser workflows. |
| Training and model-building resources | Compact reference implementations for models and training stacks. | karpathy/nanochat, karpathy/llm.c. |
| Multi-agent orchestration | Role-based collaboration and durable workflow graphs. | AutoGen, CrewAI, LangGraph, MetaGPT. |

## How This Connects Back to Scientific Agents

- Training repositories help readers understand the model substrate behind agent behavior.
- Coding agents provide practical patterns for repository-scale action, testing, and repair.
- Browser agents show how agents collect information from ordinary web interfaces.
- Multi-agent frameworks provide reusable orchestration patterns for scientific workflows.
- Auto-research systems combine these pieces into long-horizon research pipelines.

## Watchlist Criteria

Add a repository when it satisfies at least one of these conditions:

- It implements an end-to-end research or software-engineering workflow.
- It introduces a reusable agent orchestration pattern.
- It provides a strong open-source baseline for coding, browsing, tool use, or model training.
- It is actively used as infrastructure by scientific-agent systems.
- It is historically important for understanding agentic automation.
